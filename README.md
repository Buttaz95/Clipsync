# ClipSync

Chat-style clipboard between your PCs (Edge extension) and iPhone (home-screen web app), on a free Supabase backend.

- **iPhone app:** https://buttaz95.github.io/Clipsync/ — open in Safari → Share → Add to Home Screen.
- **Edge extension:** the `extension/` folder — `edge://extensions` → Developer mode → Load unpacked.

Data is protected by your Supabase login (row-level security). The key in the code is Supabase's public "publishable" key, which is safe to publish.
